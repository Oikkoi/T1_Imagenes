### Boceto 1:
La función `ColorSaturationHSV` recibe dos argumentos. El primero, el nombre de archivo de la imagen (que debe estar dentro de la misma carpeta que `P1.py`). El segundo es una lista con pares ordenados *`(h_i, m_i)`*. Si bien el código está preparado para recibir valores de *`m_i`* negativos, se esperan valores positivos. El valor neutro de `m` es 1.
